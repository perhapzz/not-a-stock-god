# 我不是股神 (Not A Stock God)

一款微信小程序股票模拟交易游戏。穿越到历史某一天，用100万初始资金在真实A股日K数据上进行买卖操作，看看你能赚多少！

## 🎮 玩法

1. 选择一个历史日期作为"穿越"起点
2. 从沪深300成分股中选择感兴趣的股票
3. 选择游戏时间跨度（1个月或1年）
4. 在每个交易日进行买入/卖出操作
5. 游戏结束后根据总资产计算得分和排名

## 📋 交易规则

- 初始资金：100万元
- T+1交易制度（当天买入次日才能卖出）
- 涨跌停限制：±10%
- 最少买入100股，且为100的整数倍
- 使用真实历史日K线数据

## 🛠 技术栈

### 前端
- 微信小程序
- TDesign Miniprogram 组件库

### 后端
- Python FastAPI
- AKShare（A股历史数据）
- SQLite 数据库
- Docker 部署

## 🚀 部署

### 后端部署

```bash
docker-compose up -d
```

后端服务运行在 8000 端口。

### 前端

使用微信开发者工具打开 `miniprogram/` 目录，构建 npm 后即可预览。
